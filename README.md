# Vortex PT — Post-Tensioned Concrete Detailing & Shop Drawing Software

Vortex PT extracts structural models from **Bentley RAM Concept** and **ADAPT-Builder**, renders an interactive 2D CAD canvas with tendon drape profiles, and generates production-ready **AutoCAD shop drawings** plus **Excel / CSV schedules**.

## ⬇️ Download

**Latest installer (Windows 10/11, 64-bit, no prerequisites):**
👉 [Download Vortex PT](https://github.com/ahmedelkholy8/VortexPT/releases/latest)

Run the setup file, launch Vortex PT, and activate with your license key.

## ✨ Key features

- Direct RAM Concept (`.cpt`) & ADAPT-Builder (`.adm`) model extraction
- Interactive 2D CAD canvas — pan, zoom, layer control, click-to-inspect
- Continuous tendon graph: drape profiles, chair heights, elongations, jack locations
- One-click AutoCAD DXF shop drawings with title block + tendon schedule table
- Multi-sheet Excel workbook: takeoff, PT schedule, chair details, rebar BBS
- Machine-locked licensing (trial, subscription, lifetime)
